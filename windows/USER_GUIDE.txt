奥特曼桌宠 1.0.1 · Windows 10 / 11

安装版：打开 UltramanPet-Setup-1.0.1.exe，点击“安装”。
免安装版：解压 ZIP，双击 UltramanPet.exe。

安装目录：D:\Apps\UltramanDesktopPet，需要有可写的 D 盘。
位置设置：安装目录中的 data\position.txt。
卸载临时文件：D:\Apps\.UltramanPetTemp，不使用 C 盘临时目录。
免安装版放在 D 盘或其他非 C 盘后，设置保存在程序旁的 data 目录。
从 C 盘启动时，设置仍转存到 D:\Apps\UltramanDesktopPet\data。
桌面和开始菜单快捷方式默认不创建，仅在你勾选时创建。
Windows 自身的安装记录、系统缓存仍由系统管理。

鼠标靠近桌宠：先挥手，再转头看向鼠标。
单击：跳跃。双击：挥手。
按住鼠标左键：拖动到喜欢的位置。
右键：播放九种动作、调整大小、切换鼠标互动和自动走动。
右键“退出桌宠”：关闭程序。任务栏右下角托盘图标也有菜单。
默认不开机自启。运行时不联网、不需要 ChatGPT / Python。
需要 Windows 自带的 .NET Framework 4.x。

卸载安装版：先退出桌宠，再从 Windows“已安装的应用”卸载，
或运行安装目录中的 Uninstall.exe。卸载保留个人位置设置。
免安装版退出后即可自行删除解压目录。

本发布包未做数字签名，Windows 可能显示未知发布者。

English: Run Setup to install for the current user, or extract the portable ZIP
and run UltramanPet.exe. Setup installs to D:\Apps\UltramanDesktopPet. Settings
are stored in the app's data directory; launching from C: uses the D: default
for settings. Uninstall helpers are written to D:. Shortcuts are opt-in.
Windows-managed installation records and caches are outside app file storage.
Hover nearby to greet/look, click to jump, double-click
to wave, drag with the left button, and right-click for actions, size and exit.
Requires Windows 10/11 with .NET Framework 4.x; no Python, ChatGPT or network
is needed to run. Exit the pet before uninstalling. Personal position settings
are retained. Binaries are unsigned. Code is MIT; artwork rights are separate.
